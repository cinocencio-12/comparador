# Comparador de Compras

App web instalable (PWA). Desde Chrome en Android: Compartir → Comparador, con una captura o el enlace de la tienda.

## Instalar en GitHub Pages
1. Sube estos archivos a un repositorio (por ejemplo `comparador`).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)` → Save.
3. Abre `https://<usuario>.github.io/comparador/` en Chrome del móvil.
4. Menú ⋮ → *Añadir a pantalla de inicio* → Instalar.
5. Abre la app → Ajustes → pega tu clave de API de Anthropic → Guardar.

La lista y las fotos se guardan en el móvil (IndexedDB). Usa *Copiar copia de seguridad* si cambias de teléfono.
